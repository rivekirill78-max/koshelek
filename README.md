# Кошелёк

Личный учёт денег для телефона и компьютера: счета в разных валютах, доходы и расходы по категориям, бюджеты, долги, аналитика.
У каждого человека свой аккаунт (почта и пароль), данные хранятся на сервере, видны только владельцу и синхронизируются между устройствами.
Без интернета изменения сохраняются на телефоне и отправляются, когда связь появится.

Устроено просто: одна страница (`index.html`) без сборки, база данных и вход — [Supabase](https://supabase.com) (бесплатный план), хостинг — GitHub Pages.

## Запуск: один раз, около 15 минут

### 1. База данных в Supabase
1. Зарегистрируйтесь на <https://supabase.com> и нажмите **New project**. Имя — любое, например `koshelek`; регион — ближайший (например, Frankfurt); пароль базы сохраните себе.
2. Когда проект создастся: **SQL Editor → New query**, вставьте всё содержимое файла [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Должно появиться «Success».
3. **Project Settings → API** (или **Data API**): скопируйте **Project URL** и ключ **anon / publishable**.
   Ключ `service_role` / `secret` **не копируйте и никуда не вставляйте**.

### 2. Подключить приложение к базе
Откройте [`config.js`](config.js) и вставьте два значения:
```js
window.KOSHELEK_CONFIG = {
  supabaseUrl: 'https://ваш-проект.supabase.co',
  supabaseAnonKey: 'ваш anon-ключ'
};
```
Anon-ключ публичный: он защищён правилами доступа из `schema.sql`, каждый пользователь видит только свои строки.

### 3. Опубликовать на GitHub Pages
Репозиторий → **Settings → Pages** → **Source: Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
Через 1–2 минуты приложение откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### 4. Адрес приложения в Supabase
Supabase → **Authentication → URL Configuration**:
- **Site URL** — адрес приложения из шага 3;
- в **Redirect URLs** добавьте тот же адрес.

Это нужно, чтобы ссылки из писем (подтверждение почты, сброс пароля) вели в приложение.

По желанию: **Authentication → Sign In / Providers → Email → Confirm email** можно выключить — тогда вход работает сразу после регистрации, без письма.

## Установка на телефон
- **iPhone**: откройте адрес приложения в Safari → «Поделиться» → «На экран „Домой“» → «Добавить». Откройте значок и войдите — один раз.
- **Android**: Chrome → меню ⋮ → «Добавить на главный экран».

## Переезд из кошелька в Claude
В старом кошельке: **Настройки → Сохранить копию** (сохранится файл `.json`).
В новом: войдите, создайте кошелёк, затем **Настройки → Восстановить из копии** и выберите этот файл.

## Обновления
Любое изменение, отправленное в ветку `main`, появляется у всех при следующем открытии приложения. Данные пользователей лежат в Supabase и при обновлениях не трогаются.
Правило для изменений кода: не переименовывать таблицы (`wallets`, `transactions`, `debts`) и поля внутри `data`, только добавлять новые — старые данные должны открываться в новой версии (см. функции `norm*` в `index.html`). При изменении файлов приложения поднимайте номер `CACHE` в `sw.js`.

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | всё приложение: интерфейс, логика, работа с базой |
| `config.js` | адрес и публичный ключ Supabase |
| `sw.js` | работа без интернета и быстрый запуск |
| `manifest.webmanifest`, `icons/` | установка на экран телефона |
| `supabase/schema.sql` | таблицы и правила доступа |
